# Туши огонь

Пиксельная головоломка в стиле сокобана: толкай бочки с водой на костры и туши их. 30 уровней, музыка, русский и английский языки.

- `index.html` — вся игра в одном файле.
- `tools/levels.py` — генератор и решатель уровней (все 30 уровней проверены).
- `tools/build_yandex.py`, `tools/make_promo.py` — архив и промо-картинки для Яндекс Игр (`yandex/`).
- `android/build-apk.sh` — сборка APK. Готовый APK — в Releases.
